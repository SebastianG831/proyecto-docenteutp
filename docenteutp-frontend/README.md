# DocenteUTP Frontend (React + Vite + TypeScript)

Interfaz web interactiva para **DocenteUTP**, construida con React, Vite y TypeScript siguiendo los mockups validados en Figma y el stack de referencia (`React.js + Node.js/Express + PostgreSQL`).

## Desarrollo local

```bash
npm install
npm run dev
```

El servidor de desarrollo corre en `http://localhost:5173` y redirige las llamadas `/api/*` al backend en `http://localhost:8080`.

## Build de producción

```bash
npm run build
```
